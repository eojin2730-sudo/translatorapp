# 시엔위 한국어 실시간 번역기 (Android)

갤럭시 S24용 실험적 자동 화면 번역 앱. Android MediaProjection + ML Kit 중국어 OCR + 오프라인 중→한 번역 + 화면 오버레이를 사용합니다.

## GitHub에서 APK 빌드하기 (PC 불필요)
1. 이 ZIP을 풀어 GitHub 저장소 루트에 **폴더 구조 그대로** 업로드합니다. GitHub 웹은 폴더 업로드가 불편하므로 PC 없이 하려면 GitHub 웹에서 파일을 하나씩 만들거나, GitHub 모바일 호환 Git 클라이언트로 폴더 전체를 푸시해야 합니다.
2. 저장소의 **Actions** → **Build Android APK** → **Run workflow**를 누릅니다.
3. 성공 후 해당 실행 페이지의 **Artifacts** → **XianyuTranslator-APK**를 다운로드합니다.
4. ZIP에서 `app-debug.apk`를 꺼내 갤럭시에서 설치합니다. 필요시 해당 파일 앱의 '알 수 없는 앱 설치' 권한을 허용합니다.
5. 오버레이 권한 허용 → 번역 시작 → 화면 공유 허용 → 시엔위 실행.

## 제한사항
- 실험용 프로토타입이며 실제 S24에서 빌드/동작 검증은 아직 하지 않았습니다.
- 중국어 OCR이 실패하거나 번역 위치가 어긋날 수 있습니다. 최대 35개 텍스트 블록을 약 1.8초 간격으로 처리합니다.
- 화면을 캡처하는 동안 민감한 앱 화면을 열지 마세요. 캡처 영상은 앱 내부에서 처리하며 서버로 업로드하지 않습니다.
- Android가 화면 공유를 중단하면 앱도 중단됩니다. 다시 시작하려면 새 동의가 필요합니다.
- 일부 보호된 화면은 캡처할 수 없습니다. 화면 공유 선택에서 '전체 화면'을 선택하세요.
- 시엔위 앱 자체는 수정하지 않습니다.
